## 实现与验证

- 新增 environmentarchitecture.ts 和 environmentbackdrop.ts；替换旧的通用几何背景，保留环境 ID 与选择入口。
- 独立建筑、地形、材质和背景着色器；自由观察视角扩大建筑展示范围，瞄准/俯视继续承担击球视角。
- 静态几何按材质合批；低档每套建筑最多 6 个绘制批次、8000 三角形。七色分光使用顶点颜色，低档保留色彩。
- 环境切换释放本套建筑几何和材质；测试检查场景唯一性、低档预算、球桌正上方净空及资源释放。
- 八个环境均做了浏览器实际取景检查；修正了神殿基岩穿地、地球取景、海底玻璃与穹肋不一致、奖杯支撑、座椅和望远镜轮廓。
- 首页和账户页的场景预览直接导出自同一版游戏渲染器，8 张 WebP 合计约 465 KiB；预览固定使用象牙球台，界面已标注。
