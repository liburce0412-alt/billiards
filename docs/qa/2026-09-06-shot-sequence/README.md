# 完整击球流程、擦粉与对手旁观

## 改动

击球入口此前直接施加物理冲量，机器人走位动画没有约束击球时机。现在所有可渲染的本地击球、AI 来球和回放共用准备流程：等待球手到位、俯身和方向稳定，再静置瞄准 0.45 秒，播放 0.65 秒拉杆及前送，接触时启动物理冲量。准备期间不推进下一条比赛事件；离开控制器会取消未发生的击球。本地击球消息也在接触时发送。

击球后的停留与起身阶段继续约束机器人，即使球很快停住，也不会提前走动或重复俯身。管理员演示的强制第一视角不再每帧清除击球后的镜头停留。

对手的 WatchAim / WatchShot 回合默认平滑切换到整桌俯视；玩家回合恢复所选击球视角，主动自由观察仍可使用。顶部新增「擦粉」按钮，仅在玩家瞄准姿态就绪时可用。动画持续约 2.4 秒，显示当前所选球杆及第一人称机械手和巧粉，完成后恢复输入与原视角，不修改击球参数。
