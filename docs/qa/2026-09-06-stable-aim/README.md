# 稳定瞄准与随身球杆

## 行为

- 走位时携带当前玩家选中的完整球杆模型、纹理和材质；等待方保留自己的球杆样式。
- 球杆绑定持杆手，随步态移动。机器人到位并俯身后才显示击球球杆，走位期间不会提前在桌边出现。
- 小幅左右微调保持脚位和俯身姿态；大幅改向停稳 250 毫秒后才换位。蓄力和出杆动画不再改变脚位目标。
- 保留出杆后的停留、第一人称起身、第三人称行走和另一名球手避让。
