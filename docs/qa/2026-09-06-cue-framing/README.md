# 库边出杆与起身修复

## 原因与改动

库边的机器人脚位受到绕桌路径约束，固定头部偏移使瞄准眼位离母球过近。修复前，新增的四组近库球位检查失败：母球投影的纵坐标低于 -3，落在屏幕下方。现在俯身眼位跟随母球和出杆轴线，保留后退距离；起身时平滑过渡到站立眼位。

新瞄准方向需要短暂稳定后才开始走位。原实现把这段等待错误地当作俯身机会，产生“起身、趴下、再起身”。现在已经站起且尚未到位的球手保持站立，抵达下一次击球位置后才俯身。

机器人和相机共用 1 秒的出杆停留时间，随后用 1.1 秒起身。保留第一人称起身、第三人称行走、球手避让、所选球杆随身携带与小幅微调稳定性。

## 验证

- Jest：114 套、835 项通过。
- 新增 9 组球位/角度的母球与球杆屏幕投影检查；30 / 60 / 120 FPS 下验证出杆停留与换位前不重复俯身。
- Playwright：`cue-framing`、`stable-aim`、`player-perspective`、`responsive` 共 16 项通过。
- 桌面鼠标和手机横屏触控均实际操作拉条出杆，采样验证杆头在画面中且模型可见；无页面异常。
- `yarn prettify`、`yarn lint`、`yarn dev`、`yarn build`、`yarn lint:css`、`yarn audit:origins` 通过。
- 截图来自实际本地 WebGL 渲染；手机真机手感、线上登录后的完整游戏未在本次自动化中验收。
