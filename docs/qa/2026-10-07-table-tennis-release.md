## 实施内容

- 将发球改为非持拍手托球、独立竖直抛起、下降时真实接触；有限拍面依据法向、相对速度、摩擦与旋转产生反弹，不再反算一个保证落台的出球速度。
- 轻挡、平击、上旋、扣杀有不同拍面与挥拍动作；力度、上下旋、侧旋独立控制，空格读取当前配置。提前/过晚会挥空，低球扣杀保留失误风险。仍有辅助站位，旋转通过滑块设置，未宣称实现完整自由手腕或手势曲率识别。
- Blender MCP 中重建带实际球拍的握姿、拇指/食指支撑和掌心托球，保存 `.blend`、GLB 及多角度动作截图。运行时同一物理拍面驱动腕部；恢复每帧 authored pose，防止 IK 累积。第一人称前臂连接到画面底部，站位镜头平滑跟随、触球附近收敛晃动。
- 白球降低粗糙纹理，台面改深蓝抗眩材质。场馆卡片改为实际场景的 Blender 渲染预览，保存上次场馆/模式/难度选择。实际游戏视角与卡片灯光不同。
- 共用浅深主题、三种配色、Classic/Fluid、边缘追光与动效开关。主要面板采样同一真实背景画布，边缘折射不改变文字或输入位置；低画质静态降级。台球顶部/设置和乒乓球比分/操作复用材质，局内保持高对比前景。
- 修正关闭外观面板残留光学区域、HUD 文字刷新破坏节流、WebGL 恢复未重建资源、关闭动效后指针仍改变背景等问题。
