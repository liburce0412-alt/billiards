# 对上一轮乒乓球与玻璃更新的审计

审计对象：主站 `261007.16`、乒乓球独立仓库 `2b7bd04`、模型 `eee7d140e66a13db`。该记录先写旧版事实，后续修复另列，不用新实现覆盖原问题。

结论：上一轮有代码和资产更新，但没有达到“姿态合理、上手教学完整、操作适合快速回合、Caesar 液态玻璃效果完整落地”。构建通过、Blender 导出、拍心误差小，均不能替代这些体验验收。此前完成汇报的措辞过宽。

## 优先问题

1. **P1，手臂/关节错误。** 第一人称为塞入画面而独立移动肩根，右肩从约 1.402m 降到 0.797m，左肩从约 1.295m 降到 0.834m，脱离躯干；随后的 IK 和强制手腕四元数以触点对齐优先，没有关节角度或手臂穿插检查。最终截图中的交叉前臂和折腕是实际问题。源动画“转体”还写错骨骼旋转轴。不是增加指头细节就能修好。
2. **P1，回球控制负担大。** 只有空格和左右箭头，球技依赖点击按钮、旋转依赖三个滑块。上下拖动不控制旋转；普通点击因位移不足 8px 被忽略。鼠标移动用绝对横向瞄准，释放拖动却改用相对位移，存在控制含义不一致。
3. **P1，教学被简化成提示。** 三条提示依赖发球/任意触球事件推进，没有轻重击任务或有旋合法回球判据，没有失败重试教学、重看或首次完成记录。帮助入口主要仍指向台球说明。
4. **P1，玻璃效果未达标。** 实际浅色画面是大片白色/粉色雾状渐变与白描边。真实采样代码存在，但边缘偏移很弱且背景缺少可辨结构；暗色 Classic/Fluid 的结果相同。部分页面、暂停与账号弹窗只有 CSS 模糊/白色填充，不能说整套材质已推广。
5. **P2，挥空反馈错误。** 早挥、晚挥都提示“等球靠近后再出拍”，会让晚挥用户继续等。
6. **P2，练习无法局内重开。** 再来一局只有比赛结束才出现；练习模式不结束，暂停里没有重开。

详见独立审计：[控制与教学](../../packages/table-tennis/docs/audit/2026-10-07-controls.md)、[关节与动作](../../packages/table-tennis/docs/audit/2026-10-07-robot.md)、[前端玻璃](2026-10-07-glass-audit.md)。

## 参考资料审计

上一轮有 Table Tennis England 教学图文来源与模型检查截图，没有已核验的其他乒乓球游戏试玩、真人视频逐帧动作对照记录。不能把打开教学链接写成“参照真人视频完成了自然动作”。

本次重新核对的公开来源：

- [Table Tennis England 正手教学](https://newsarchive.tabletennisengland.co.uk/news/archived/developing-forehand-strokes/)：重心转移、躯干转动、引拍与随挥关系。
- [PingSkills 握拍教学页](https://www.pingskills.com/tutorials/table-tennis-strokes/how-to-hold-the-bat-shakehand-and-penhold)：横拍/直拍基础；视频入口可定位，但本次嵌入视频抓取被限流，未声称看完视频。
- [Table Tennis Touch 开发者介绍](https://tabletennistouch.com/)与[官方商店说明](https://play.google.com/store/apps/details?id=uk.co.yakuto.TableTennisTouch)：直接滑动操作、旋转与训练是同一游戏循环的一部分。借鉴的是减少菜单切换的交互方向，不宣称照搬其物理算法；官方 Vimeo 视频导航超时，未取得可核验逐帧观看结果。

## 本轮实际修正

| 要求 | 本轮实现 |
| --- | --- |
| 主动控制不同球路 | 统一鼠标绝对 X 瞄准；点击轻挡，短蓄力后松手出拍，上下刷动加旋；Q/W/E/R 按住并松开直接出轻挡/平击/上旋/扣杀，A/D 可跨拍保持侧旋。力量、时机、落点仍影响成败。精调收起后不必移开鼠标选动作。 |
| 触球与失误反馈 | 保留真实触球/判分事件，挥空依据球距拍面的时间区分偏早、偏晚和无法确认的未接触；不把所有失误说成太早。 |
| 短教学 | 练习中依次要求合法发球、轻重合法回击、实际上旋落台；只认本人触球，重球须有实际离拍速度差。失败保持当前目标；可跳过、重看，完成记在本机。 |
| 比分 | 保留独立小分、胜局、发球方；透明面板保持前景文字对比。 |
| 连续试玩 | 保留模式/难度/场馆记忆；离线暂停提供重开练习/再来一场，联机不允许单方重置权威比赛。 |
| 透明界面和说明 | 大厅可见边缘折射与结构化背景，深色 Classic/Fluid 分开；局内只在窄边带折射，装饰层不收指针。暂停/结果弹窗增加实际场景采样及文字背景抑制；帮助页新增完整鼠标/键盘/触屏说明，并使用 `/tools` 避免 `/help` 被旧静态台球页面抢占。 |
