## 最终近景检查与三处实体修复

实际逐张查看了全部八环境的新四视图及 `environment-<id>-detail-0.png`。Club 沙发座垫缝边、Galaxy 控制台/螺栓、Sky Temple 柱环/檐口、Abyss 肋架连接的微表面尺度已减弱，没有原先过大的墙面法线波纹。它们保留风格化建筑表现，不是扫描资产。

在最后近景中继续发现三处实体问题，并通过真实 Blender MCP 修改、重新导出和再次截图复核：

1. **Aurora 雪地棋盘伪影。**低洼山地与底板相交，加上旧批次法线影响造成规则黑白三角。保留原山形和基础高度，把远处雪面拆为独立、朝上的平滑高度场并抬高低洼点；最终全景与柱脚近景中规则棋盘已消失，中央冰平台未被移动。
2. **Nebula 球壳与金属环交穿。**两处球形万向壳重新建为 64 段平滑球面；第二次近景发现部分银色尖痕是过小的金属环穿过球壳，继续增大环半径。最终近景可看到完整环体绕过球壳，不再有原尖锐夹痕。
3. **Lunar 天线碟缺面。**原反向单面旋转曲面从上方被剔除，能直接看到背景陨坑。换为闭合 18mm 抛物面壳；最终近景显示实体碟遮挡背景并接收馈源支撑的阴影。

三项重建均保持运行时 shader 代理的顶点数、面数、材质与世界变换不变，脚本在导出前检查该约束。最终角度图、近景和 review 与当前 GLB 匹配。

SPECTRA 的 [实际 WebGL 近景](spectra-runtime-prism-close.png) 及 `spectra-runtime.json` 已由主站验收者确认：可透过棱镜看到墙纹、地板和底座，Blender 灰颗粒预览不再当作生产玻璃表现。天空/水体动画、完整对局相机与真实手机性能仍不由这些静态 Blender 图证明。
