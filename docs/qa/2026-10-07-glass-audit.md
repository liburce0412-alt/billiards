# 261007.16 共用玻璃与前端复核

## 结论

## 为什么仍像白卡或普通透明框

1. 浅色背景以接近白色的底色和大面积低频雾团构成；即便正确采样，平坦区域也没有足够的结构显示折射。
2. 模型只有一条窄亮边和小幅偏移，缺少可见的边缘厚度带、内外反光与触点方向变化。
3. 历史 `--glass-paper-soft` / `--glass-paper-medium` 为 50% / 70% 白色，部分选择项仍直接使用它们；旧账户弹窗又叠加白罩和白卡。
4. 固定取 DOM 前三个光学区域，没有弹窗优先规则；存在区域被其它卡片占用的风险。

## 本轮修正方向及证据边界

先修共享材质和控制语义，再检查真实浅/深大厅与局内小样。大厅强化可辨的边缘厚度、结构化背景和连续触点反光；局内限制折射在面板边缘，中心不扭曲球路，文字及输入区域保持原位。注册暂停/结果等实际弹窗，加入区域优先级；主题纸白残留与动态开关联动统一处理。

模型动作、教学、操作方式由各自实现记录跟踪。本文件记录旧版问题，不代表后续修正自动通过视觉验收；真实浏览器画面与用户试玩是独立证据。

### 审计后已写入的修正

- 光学层使用圆角距离场法向、双层边缘反光、连续触点高光和窄带 RGB 分离；大厅折射宽度为 14px、幅度为 11px，局内缩为 7px / 2.2px，中心不位移。
- 浅色 Fluid 加入连续曲线结构；深色 Classic 使用低幅宽带，Fluid 使用带折叠的光幕，避免两档输出相同。
- `a`、`textarea` 等加入交互注册；原生输入框用非拦截轮廓反馈；总动效关闭同时约束根内 CSS 动画、过渡及按压变形。
- 暂停/结果/账户弹窗优先注册，单个采样画布位于打开的模态罩之上、文字之下；关闭恢复原层级。并保持最多三个可见光学区域。
- 统一历史半白材质 token、登录区域薄底色和教学页面排版；纯 DOM 内容没有被背景画布捕获，仍不声称能够折射任意网页文字或图片。

源码格式、定向 ESLint 和新增 CSS 的 stylelint 已通过。新材质效果还需主任务在最终构建中查看浅/深小样；这里没有提前记录“Caesar 视觉已达标”或生产互动通过。
