# 出杆后的停留与起身视角

2026-09-05，版本 260905.21。

- 3D 瞄准视角出杆后保持原位置和朝向 0.85 秒，再用 1.1 秒平滑抬高观察。
- 观察位置固定在出杆处，不随运动中的母球移动；下一杆开始时平滑回到母球后方。
- 单指俯仰、双指环绕、缩放和 2D/3D 切换可接管相机；手动选择的 2D 和自由视角在出杆时保持不变。
- 球离开可视范围时的渲染建议不再提前取消停留；玩家、旁观和回放进入下一杆时结束上一杆观察。

验证：812 项 Jest 测试（113 个套件）、12 项响应式浏览器测试通过。新增原生触摸出杆测试逐帧检查母球运动时相机位置和朝向保持不变，随后只抬高观察位置。另验证 30/120 Hz 一致性、连续出杆重置和手动接管。通过 lint、CSS lint、prettify、dev、build 和外部来源审计。浏览器触摸模拟不等同于实体手机手感验收。
